# 틱택토 (Tic-Tac-Toe) 게임

사용자 vs. 컴퓨터 1:1 틱택토 웹 게임입니다. 플레이어가 항상 선공(X)으로
시작하며, 쉬움(랜덤 AI)/어려움(미니맥스 AI) 두 가지 난이도를 실행 시 선택할
수 있습니다. 게임이 승/패/무승부로 끝난 경우에만 결과가 난이도별로 집계되어
저장되고, 전적 조회 화면에서 쉬움/어려움 전적을 각각 확인할 수 있습니다.
(게임 도중 새로고침/다시 시작 등 중간 이탈은 기록되지 않습니다.)

## 기술 스택

- 백엔드: Spring Boot 4.1.2 (Java 21), REST API
- 저장소: SQLite (`tictactoe.db`)
- 프론트엔드: 순수 HTML/CSS/JavaScript (정적 리소스로 서빙, 게임 로직은
  브라우저에서 실행)
- 빌드: Gradle Wrapper (`./gradlew`)

## 실행 방법

```bash
./gradlew bootRun
```

애플리케이션이 뜨면 브라우저에서 `http://localhost:8080` 에 접속합니다.

## 테스트 방법

```bash
# Java 테스트 (단위 + 통합 테스트)
./gradlew test

# 프론트엔드 순수 로직(JS) 테스트
node --test src/test/js/*.test.js
```

## 기능 요약

- **난이도 선택**: 게임 시작 시 쉬움/어려움 중 하나를 선택합니다.
  - 쉬움: 컴퓨터가 가능한 수 중 하나를 무작위로 선택합니다.
  - 어려움: 미니맥스 알고리즘으로 최적의 수를 두므로 이길 수 없습니다
    (승리 또는 무승부만 가능).
- **선공 고정**: 플레이어가 항상 X로 먼저 둡니다.
- **전적 기록**: 게임이 끝까지 진행되어 승/패/무승부가 확정된 경우에만
  `POST /api/results`로 결과가 저장됩니다. 중간에 새로고침하거나 "다시
  시작"을 누르면 기록되지 않습니다.
- **전적 조회**: `GET /api/stats`로 난이도별(쉬움/어려움) 승/패/무승부
  집계를 조회할 수 있으며, 화면 하단의 전적 패널에 표시됩니다.
